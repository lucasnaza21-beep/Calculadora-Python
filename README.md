# 🐍 **Calculadora python automatica**

### Sobre o projeto:
 - Este projeto é um sistema de calculadora com linguagem amigável e simples para novos usuarios.

### **Objetivo:**
- Fazer operações matemáticas: Soma, Subtração, Multiplicação, Divisão, Potenciação, Radiciação.

### **Principais Características:**
- Funcionamento: Calcular (`a, b, operacao`): Função principal que recebe dois números e realiza o cálculo de acordo com a operação selecionada. 
- Requisitos: Python 3.8 ou superior.  

### **Como Executar o Script Shell** (`calculadora_linux.sh`)
- O script Shell automatiza o programa e chama a execução da calculadora em Python.
- Conceder permissão de execução:
```bash
  chmod +x calculadora_linux.sh
```
- Comando para executar o Arquivo:
```bash
./calculadora_linux.sh
```

### Arquivo Executável
 - O arquivo executável está disponível na raiz do repositório:
 ```bash
 ./calculadora_linux
```
